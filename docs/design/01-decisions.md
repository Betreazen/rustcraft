# RustCraft: журнал решений опроса

Решения автора по ходу опроса. Источник для будущей спецификации. Более поздняя запись отменяет раннюю, если они расходятся.

## Порядок работы (решение автора, 2026-11-10)

Код пишется последним. Порядок:

1. Опрос и обсуждение всех систем.
2. Окончательная спецификация.
3. Большая HTML-витрина в духе вики: все блоки и предметы, рецепты, прогрессия и способ получения, что на чём делается, схемы подключения, миниатюры структур, анимации там, где они нужны для понимания.
4. Вся графика и модели: вагонетки, монорельс, трубы, блоки, броня, иконки. Готовы до кода, чтобы код сразу к ним крепился.
5. Код.

## Раунд 1. Основа (2026-11-10)

| Вопрос | Решение |
| --- | --- |
| Что делаем первым | Обе системы тонким срезом: простая магистраль и простой монорельс одновременно, глубина позже |
| Роли труб и вагонеток | Трубы работают внутри базы на коротких расстояниях; дальние перевозки, работа в поле и поездки игрока идут по монорельсу. Способ ограничить трубы (длина или цена) не выбран |

## Раунд 2. Магистраль (2026-11-10)

| Вопрос | Решение |
| --- | --- |
| Конструкция | Корпус с гнёздами: дешёвый корпус-труба, каналы добавляются в него по мере надобности |
| Состав каналов | Четыре гнезда, в каждом любой канал на выбор игрока (например два предметных, жидкость и энергия) |
| Движение предметов | Сервер переносит предметы по правилам сети без физических объектов в трубе; клиент показывает поток через окошки корпуса |
| Настройка потоков | В начале игры настройка на стыке с машиной (ввод, вывод, фильтр, приоритет). Дальше по прогрессии открывается умная сеть заказов: машины сообщают, что им нужно, склад выдаёт |

## Раунд 3. Монорельс: основа (2026-11-10)

| Вопрос | Решение |
| --- | --- |
| Кабина и камера | Кабина и игрок всегда вертикальны; меняется только место крепления: рельс под кабиной, сбоку или над ней. Переворотов нет |
| Геометрия пути | По сетке блоков: рельс крепится к грани блока; повороты на 90°, подъёмы, вертикальные участки и переходы между поверхностями собираются из нескольких видов сегментов |
| Пассажирская вагонетка | Станция вызывает капсулу за энергию; по прибытии капсула исчезает. Вагонетки-работники остаются настоящими предметами |
| Встреча на одном пути | Вагонетки проезжают друг сквозь друга, столкновений, сигналов и пробок нет |

## Раунд 4. Монорельс: станции и работники (2026-11-10)

| Вопрос | Решение |
| --- | --- |
| Карта сети | Схема метро: станции-точки с названиями, линии и развилки, расстояние и время в пути. Строится сама по проложенным рельсам |
| Скорость и энергия | Скорость задаёт уровень рельса. Рельсы пассивны; энергию за поездку списывает станция отправления, цена растёт с расстоянием |
| Вагонетка-работник | Одно шасси, один рабочий инструмент (пила, жатка, бур, захват) и несколько улучшений (ёмкость, батарея, скорость, радиус) |
| Поведение работника | Автоматическое: ездит по своему пути и работает вдоль него; при полном трюме сама едет к блоку разгрузки, при низком заряде сама едет на зарядку. Расписаний нет |

## Раунд 5. Энергия (2026-11-10)

| Вопрос | Решение |
| --- | --- |
| Модель энергии | Одна единица энергии, без напряжений, трансформаторов и взрывов. Уровень энергоканала ограничивает, сколько энергии проходит в секунду |
| Дальность магистрали | Сеть работает на ограниченной длине трубы от узла сети, предел растёт по уровням (например 32, 64, 128 блоков; числа не утверждены). За пределом труба не работает и явно это показывает |
| Скорость машин | Регулятор режима на каждой машине: экономный, обычный, форсаж. Быстрее значит непропорционально дороже по энергии. Модули расширяют диапазон режимов |
| Кристаллы энергии | Генератор с подпиткой: один кристалл даёт немного энергии бесплатно и всегда (дешёвый старт); структуры дают намного больше суммы кристаллов, но требуют расходника, который подвозится трубами. Расходник не выбран |

## Ограничения движка, найденные исследованием (2026-11-10)

Подробно: `docs/research/horizon-modding-capabilities.md`. В игре ничего из этого не проверялось.

- Блоки, предметы, block entity, экраны со слотами, свои сетевые сообщения, баки и буфер энергии в движке есть готовые.
- Своего класса сущности нет, ванильная вагонетка привязана к рельсу под собой. Монорельс на стене и потолке — самая дорогая и рискованная часть.
- Крена камеры нет: решение «кабина всегда вертикальна» с этим согласуется.
- Дополнительных слотов инвентаря игрока нет; рюкзак возможен как предмет со своим экраном (до 256 слотов).
- Свои жидкости существуют только внутри баков и труб, без источников в мире и вёдер.
- В непрогруженных чанках тиков нет; удержание чанков рассчитано на десятки чанков и не сохраняется между запусками.
- Сервер не может задать скорость игроку: тяга джетпака и подтягивание крюком делаются на клиенте и конфликтуют с античитом выделенного сервера. Полёт в стиле творческого режима работает штатно.
- Код IndustrialCraft 2 закрыт (All Rights Reserved), брать его нельзя; идеи и числа из вики использовать можно.

## Раунд 6. Риск монорельса, работа без игрока, машины (2026-11-10)

| Вопрос | Решение |
| --- | --- |
| Риск монорельса | Исключение из правила «код последним»: сначала маленький черновой прототип только движения капсулы по стене, потолку и вертикали, без графики и остальных систем. Сборку запускает автор (флаг доверия к нативному коду даёт только владелец). По результату уточняется спецификация монорельса |
| Работа без игрока рядом | Якорь базы: блок держит прогруженной небольшую область (например 3×3 чанка), пока владелец в сети, и потребляет энергию. По одному якорю на игрока, позже больше |
| Машины первой версии | Электропечь, дробилка (из одной руды два слитка), автокрафтер, установщик и разрушитель блоков |
| Автокрафт | Один блок со страницами, на каждой странице один рецепт. Число страниц увеличивается модулями |

Открыто: согласовать удвоение руды дробилкой с бонусами шахтёра в Path-of-craft-tree.

## Раунд 7. Добыча и живая жила (2026-11-10)

| Вопрос | Решение |
| --- | --- |
| Добытчик руды | Неподвижный блок со сканером: сканирует область под собой (радиус растёт по уровням и модулям), по одной вытягивает руды за энергию и заменяет их камнем. Рельеф не меняется |
| Вагонетка-проходчик | Отдельная вагонетка-работник. Её задача не добыча, а прокладка пути: бурит тоннель под монорельс, сама укладывает монорельс и делает путь безопасным (не ведёт через лаву и в лаву) |
| Живая жила: выбор руды | Случайная руда по весам: частые руды чаще, редкие реже. На каждый блок уходит камень и энергия. Выбрать конкретную руду нельзя |
| Живая жила: состав | Все руды игры, включая древние обломки, редкие с очень малым шансом |
| Доля опыта Path-of-craft-tree | Механизм даёт владельцу 50% опыта от того же действия руками. Число живёт в файле данных |

Риски, отмеченные при обсуждении:

- При 50% и якоре базы большая ферма прокачивает быстрее, чем игрок руками. Дерево Path-of-craft-tree придётся пересчитать под это или добавить потолок.
- Живая жила со всеми рудами делает эндгейм-ресурсы достижимыми без вылазок. Баланс держится только на весах, скорости и цене энергии.

## Раунд 8. Склад (2026-11-10)

| Вопрос | Решение |
| --- | --- |
| Форма склада | Мультиблок из блоков-ячеек любого размера в форме параллелепипеда, ёмкость растёт с числом блоков. Весь склад открывается через терминал: одно окно со страницами и поиском |
| Ёмкость | Слоты, как в сундуке: каждая ячейка добавляет страницу слотов. Модули увеличивают размер стака (64, 256, 1024 и дальше; числа не утверждены). Те же модули подходят рюкзаку |
| Лимит по предмету | Настраивается для каждого предмета. По умолчанию при достижении лимита склад перестаёт принимать предмет, и производство останавливается; для выбранных предметов игрок включает уничтожение излишка |
| Доступ | Основной терминал у склада, дополнительные терминалы в любом месте базы, куда дотянута магистраль. Поздно в прогрессии появляется планшет для доступа в пределах базы без проводов |

## Раунд 9. Снаряжение игрока (2026-11-11)

| Вопрос | Решение |
| --- | --- |
| Джетпак | Свободный полёт как в творческом режиме, пока есть заряд: зависание и полёт в любую сторону, скорость ограничена, энергия тратится каждую секунду. Реактивной тяги нет |
| Гарпун | Проверяется вторым маленьким прототипом вместе с монорельсом: получится ли плавное подтягивание без срабатывания античита. Если да, входит в мод; если нет, откладывается |
| Модули игрока | Ставятся в гнёзда технической брони, работают, пока броня надета и заряжена, тратят её энергию. Постоянных пассивных улучшений нет, чтобы не дублировать Path-of-craft-tree |
| Рюкзак | Предмет в обычном слоте инвентаря, открывается клавишей или правым кликом. Уровни дают больше слотов, модули увеличения стака общие со складом. Слот брони не занимает |

## Раунд 10. Маяк, зелья и чары, защита, конвейеры (2026-11-11)

| Вопрос | Решение |
| --- | --- |
| Маяк мобов | В RustCraft его нет: структура, управляющая спавном и силой мобов, целиком уходит в будущий мод с врагами |
| Зелья и чары | Оба направления. Катализаторы: инженерные зелья заливаются в машины по жидкостному каналу и на время дают эффект (ускорение, экономия энергии, шанс дополнительного выхода); варятся из продукции ферм. Чары: небольшой набор технических зачарований для брони и инструментов (ёмкость батареи, экономия заряда и подобные) через ванильный стол зачарований |
| Защита базы | И вагонетка-страж (инструмент «стрелок» для шасси работника, патрулирует кольцо монорельса), и неподвижная турель-блок за энергию |
| Конвейеры | Конвейерных лент нет |

## Правила, принятые по итогам исследований без отдельного вопроса

Автор может отменить любое из них.

- Предмет никогда не выпадает из магистрали: сеть не забирает предмет из источника, пока для него нет места в приёмнике.
- Режим ввода и вывода задаётся отдельно для каждого канала на каждой грани (общий флаг на сторону приводит к тому, что труба высасывает энергию из машин-потребителей).
- При нехватке энергии машины замедляются пропорционально, а не останавливается вся сеть.
- Добытчик выбирает руду по белому списку и заменяет её породой, которая была вокруг (камень, глубинный сланец, незерак).
- Одна единица энергии на весь мод с первого дня.

## Раунд 12. Сплавы, генераторы, владение, первый срез (2026-11-11)

| Вопрос | Решение |
| --- | --- |
| Сплавы | Новых руд нет. Сплавы делаются из ванильных металлов и кристаллов в отдельной машине, плавильне сплавов. По одному сплаву на ступень: сплав служит пропуском на следующую ступень |
| Источники энергии | Кроме кристаллов: топливный генератор (уголь, дерево), лавовый генератор (лава от насоса), солнечная панель, водяное колесо и ветряк |
| Владение | Всё общее: любой игрок пользуется любой машиной, складом и станцией и может их перестраивать. Владелец запоминается только для начисления опыта Path-of-craft-tree (опыт получает тот, кто поставил машину). Сеть монорельса одна на всех |
| Первый играбельный срез | Корпус магистрали с каналами предметов, энергии и жидкости; одиночный кристалл; электропечь; дробилка; автокрафтер; насос и бак; склад с терминалом; монорельс первой ступени со станциями, схемой метро и капсулой; первая вагонетка-работник с блоками разгрузки и зарядки |

## Раунд 13. Прототип, рельс работников, движение, число ступеней (2026-11-11)

| Вопрос | Решение |
| --- | --- |
| Объём прототипа | Только монорельс и гарпун. Блоки, машины, экраны и трубы считаются осуществимыми по исходникам движка, риск принят автором |
| Рельс работников | Один монорельс на всё: работники, грузовые вагонетки и пассажирские капсулы ездят по одному и тому же рельсу |
| Видимое движение | Настоящие подвижные части у ключевых блоков (водяное колесо, ветряк, валки дробилки, инструменты вагонеток, турель, пульсирующие кристаллы). Остальные машины показывают работу анимированной текстурой, светом и потоком в окошках |
| Число ступеней | Четыре. Пятую можно добавить позже |

## Формат витрины (решение автора, 2026-11-11)

HTML-страница делается сразу как справочник инженера: анимированная сцена на каждый блок и предмет мода, плюс рецепты, прогрессия и схемы подключения. Она же служит источником сцен и текстов для внутриигрового справочника.

## Справочник: наведение и ревью (решение автора, 2026-11-11)

- При наведении на любой объект сцены показывается карточка: название, что объект делает, какие ресурсы принимает и отдаёт. Клик открывает страницу объекта.
- Справочник прошёл строгое ревью понятности. Что изменилось в правилах и какие вопросы остались, записано в разделе 11 спецификации.

## Раунд 14. Ответы после ревью (2026-11-11)

| Вопрос | Решение |
| --- | --- |
| Груз между мирами | Портальный док: парные блоки у порталов в двух мирах. Что сдано в один, выходит из другого. У дока буфер, поэтому он работает, когда другой мир выгружен |
| Ступень стоящей машины | Замена правым кликом: машина следующей ступени из руки встаёт на место старой, старая оказывается в руке. Предметы и жидкости остаются в новой машине |
| Большие структуры кристаллов | Ступенью не закрыты. Их сдерживает только число кристаллов: кристаллы нужно находить или выращивать |
| Выращивание кристаллов | Осколок-затравка вырастает в друзу, пока получает питательный раствор. Скорость подбирается плейтестом |
| Расход раствора | Начать с разумного числа, дальше подбирать плейтестом |
| Катализаторы | Подходят всем машинам, для которых эффект имеет смысл |
| Скорость капсулы | Для начала как у обычной вагонетки или чуть быстрее, в том числе вертикально. Проверить, что передвижение не роняет FPS |
| Улучшения шасси | Три гнезда у первого шасси, больше с каждой ступенью шасси, семь на четвёртой ступени. Подбирать тестами |
| Технические чары | Всегда книгой: игрок видит, какие чары в книге, и накладывает её на подходящий предмет |
