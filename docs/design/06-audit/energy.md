Пути ниже даны от `mod/rustcraft/`, если не указано другое. Только чтение, ничего не собиралось и не запускалось.

Общее про блокеры: Horizon 7e4e421 умеет рисовать блок-энтити на клиенте с позой (`translate`, `rotate_about`, `scale`; API 71), рисовать отдельные модели (`native_draw_model`, API 151) и давать блок-энтити блоку с любым шаблоном (API 129) (`docs/native-mods.md:920-923, 1183, 1247`). Поэтому все визуальные пункты ниже (цельная структура, присоски, высокий ветряк) — это работа, а не блокер. Один возможный блокер — окно у блока с шаблоном стекла (см. «Солнечная панель»). Уверенность низкая.
