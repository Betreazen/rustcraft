# Аудит: магистраль (pipe), начало (start), материалы (mat)

Репозиторий: ``, версия мода 0.17.1 (`mod/content/horizon-mod.toml:5`). Только чтение кода и данных, игра не запускалась. Пути ниже даны от корня репозитория; `SRC` — исходники Horizon `7e4e421`.

Статусы: **DONE** — как в справочнике; **DIFFERS** — есть, но иначе; **MISSING** — нет в игре; **STALE** — строка списка пробелов устарела. Объём: S меньше часа, M полдня, L день и больше.

## Главное

1. **Корпус, узел и ключ нельзя скрафтить.** В `mod/content/data/rustcraft/recipe/` 144 рецепта, среди них нет `housing`, `node` и `wrench`. Без них «Первый час» в выживании не пройти: магистраль берётся только из творческого режима или через `/give`.
2. **Узлов 2–4 ступени нет как предметов.** Блок узла хранит ступень в свойстве `tier` (`mod/rustcraft/content.rs:477-495`), но предмет один и ставит ступень 1. Рецептов ступеней нет, замены правым кликом нет. Сломанный узел любой ступени выпадает предметом первой (`loot_table/blocks/node.json`). Значит, развилка (ступень 4) и заказы, которым нужен узел 3-й ступени, в выживании недоступны, хотя код для них есть.
3. **Каналов 4-й ступени нет** (`content.rs:407-417`: девять предметов, ступени 1–3).
4. **У узла нет окна** (баланс, дальний корпус, выбор линии) и нет гнёзд под модули. Модуля «ускорение линии» нет как предмета (`rules/src/handbook/pages.rs:69`, `item: None`).
5. **Ключ не поворачивает машины и не снимает их с содержимым.** Клик по машине открывает окно стыка соседнего корпуса (`transport.rs:499-513`). Узкие места ключ не подсвечивает, фальш-панели с ключом в руке не становятся прозрачными.
6. **Полоски каналов на корпусе не окрашены.** Это не блокер: Horizon уже даёт моду всё нужное, и мод сам этим пользуется для фальш-панели и движущихся частей (рендер блок-энтити API 71, отдельные модели API 151, тег обновления API 45; `mod/rustcraft/anim.rs:1-12`, `builder.rs:425-435`).
7. **Вместо осколка кристалла — ванильный осколок аметиста, вместо друз — ванильные аметистовые жеоды.** Своего осколка нет, выращивания затравки на баке в коде не найдено.

## Что сделать, чтобы область стала игровой (по объёму)

- **S:** рецепты корпуса, узла 1-й ступени и ключа; каналы 4-й ступени (3 предмета, 3 рецепта, строки в `CHANNEL_ITEMS`); выпадение узла со своей ступенью; диагноз «Под фальш-панелью»; возврат панели и блока вида при поломке корпуса; shift + ключ по пустому корпусу снимает корпус; текст «в машину / из машины»; дробилка принимает блоки руды; закрывать окно стыка при отходе.
- **M:** узлы 2–4 ступеней (предметы, рецепты, замена правым кликом); модуль ускорения линии с гнёздами в узле; окрашенные полоски каналов на корпусе (тег обновления `slots` + тонированные модели в `native_block_entity_submit`); F4 через `collision_shapes` по свойству `covered`; F5 и подсветка узких мест с ключом в руке; поворот и снятие машин ключом с содержимым; отчёты опыта печи, плавильни и автокрафтера; катализаторы в остальных машинах; свой осколок кристалла.
- **L:** окно узла; окно стыка как в справочнике (свой экран, API 111); свой мир-ген друз и выращивание затравки.
