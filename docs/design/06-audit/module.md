# Аудит: категория справочника «Модули машин» (module)

Репозиторий: ``. Только чтение, без сборки и запуска.
Справочник: `docs/showcase/js/data.js:793-977` (записи `modules` … `mod_recipes`), правила `docs/design/02-spec.md:900-925` (A5–A7), `:1152` (A9), `:260` (S3), `:1142` (DS5), `:1165` (TR2).

Ключевые места в моде:
- Список модулей и кто их берёт: `mod/rustcraft/rules/src/modules.rs:9-176` (`Module`, `ITEMS` — 25 предметов, `Holder::takes`).
- Гнёзда окон-листов: `mod/rustcraft/rules/src/machines/sheet.rs:26` (`SOCKETS = 3`), `:114-125` (какой блок чей держатель), `:490-548` (вставка/выдача).
- Модуль ёмкости — отдельный предмет вне `ITEMS`: `mod/rustcraft/content.rs:63`, `:815-827`; работает только в автокрафтере `mod/rustcraft/crafter.rs:97-102`, слоты `content.rs:54`, правило слотов `machines.rs:1052,1088`.
- Печь/дробилка: `machines.rs:752` `modules: Vec::new()` — гнёзда не работают; окно рисует пустые гнёзда `screens.rs:423-425`; плавильня `panels.rs:188-189`; насос `fluid_panels.rs:266-267`.
- Рецепты: `mod/content/data/rustcraft/recipe/module_*.json` (24 файла) + `upgrade_*.json`. Нет `module_stack`, `module_yield`, `module_line`.
- Осколок кристалла во всех рецептах заменён на `minecraft:amethyst_shard` (записано в списке пробелов, строка 48 разд. «Что срезы пока не умеют»), ниже это не считается отличием.

Обозначения объёма: S < 1 ч, M — полдня, L — день и больше. BLOCKER — нужно то, чего API Horizon не даёт.
