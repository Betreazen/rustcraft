# Аудит: разделы справочника «craft» и «storage» против мода RustCraft

Репозиторий: `` (ветка как есть, версия 0.17.1). Пути ниже — от корня репозитория.
Справочник: `docs/showcase/js/data.js` (записи), `docs/showcase/js/ui.js` (окна), `docs/showcase/js/scenes.js` (сцены). Правила: `docs/design/02-spec.md` (S1–S8, TM1, K1–K8, BU1, раздел 22).

Статусы: **DONE** — как в справочнике; **DIFFERS** — есть, но иначе; **MISSING** — обещано, в игре нет; **STALE** — строка списка пробелов устарела.
Объём: S < 1 ч, M — полдня, L — день и больше. BLOCKER — нужен API, которого нет в Horizon `7e4e421`.

**Блокеров по этим разделам не найдено.** Всё, что нужно для недостающего, в Horizon есть: свой экран клиентского мода (`native_mod_screen_open`, API 111, `native-mods.md:1125`) — для рисованного окна планшета; рисование блок-энтити (`native_block_entity_submit`, `native_draw_block`, `native_draw_model` с оттенком, API 71/151, `native-mods.md:920-930, 1247`) — для призрака проектора, красной подсветки клетки и подсветки ячеек склада. Насколько уверен: высокая уверенность для окна планшета и подсветок; средняя — для настоящей полупрозрачности призрака (в документации нет явного альфа-канала у `native_draw_block`; обходной путь — рисовать стеклянную или тонированную модель).
