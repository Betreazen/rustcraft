# Текстуры игры для справочника

Скрипт берёт текстуры игры из клиента на этом компьютере. Справочник показывает с ними блоки, растения, предметы, Стива и зомби как в игре.

## Как запустить

Из корня репозитория:

```
py -I tools/local-mc-assets/extract.py
```

По умолчанию скрипт читает `%APPDATA%\horizon-launcher\minecraft\versions\26.3\26.3.jar`. Другой клиент задаётся ключом `--jar`.

## Что он делает

Скрипт читает из jar только нужные картинки: блоки, растения и их стадии роста, иконки предметов, сундук, Стива и зомби. Если в списке скрипта появилась новая текстура, запусти его снова. Он пишет их в `docs/showcase/local/mc-assets.js`. Справочник подхватывает этот файл сам.

## Почему файла нет в git

Текстуры принадлежат Mojang. Их нельзя класть в репозиторий. Папка `docs/showcase/local/` есть в `.gitignore`.

Без этого файла справочник работает как раньше: блоки и растения нарисованы заново, Стив и зомби в простых цветах.
